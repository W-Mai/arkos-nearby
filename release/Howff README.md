# Howff

R36S 的游戏启动器与附近联机工具。

适用配置为 ArkOS4Clone 08262026、Linux 4.4.189、RTL8188EU 无线芯片和 640×480 屏幕，详见 [设备兼容性](https://github.com/W-Mai/arkos-nearby/blob/main/docs/compatibility.md)。

## 安装

将整个 `howff` 文件夹复制到游戏卡，在掌机文件管理器中运行同目录的 `Install Howff.sh`，按画面提示完成安装。

## 打开与游玩

- **Options → Howff Launcher**：进入收藏首页和游戏库，短按 X 启动单机，长按 X 打开选中游戏的联机面板。
- **Options → Howff Nearby** 或系统主页 **FN + X**：查看附近房间、选择游戏或仅组网。
- 系统游戏列表启动时按住 **X**：为当前游戏创建或加入房间。
- **START**：打开设置、系统控制、设备与好友及应用管理。

一台创建房间，另一台选择对应房间加入。首次连接由房主确认，双方就绪后房主开始游戏。退出联机后恢复原 Wi-Fi。仅组网完成后可保持连接返回系统，再启动局域网游戏。

## 更新

将完整的新版 `.tar.gz` 安装包放到游戏卡，结束游戏与房间后，在 **START → 应用管理 → 安装更新** 中选择安装包并确认。也可以解压新版安装包，再运行其中的安装脚本。更新保留个人数据与存档备份。
