# 问题排查

## 安装提示不支持

执行 `sudo /path/to/arkos-nearby doctor`，按 `problems` 检查内核、无线 USB ID、屏幕格式和系统工具。具体配置见 [设备兼容性](compatibility.md#设备配置)。

## 找不到附近房间

房主先创建房间，另一台选择加入。确认双方选择相同游戏，在房间列表按 X 刷新，选中房间后按 A 加入。

## 停在连接、核对或等待状态

首次加入需要房主确认；进入无线连接后，工具仍需分配地址和核对本地游戏。只有收到真实就绪回执才显示等待开局。两端使用同一发布版本，检查游戏内容和核心是否一致。按 B 取消，等待网络恢复完成后重试。

## 开始游戏不可用

对端尚未就绪时开始按钮不可操作。若正在等待首次设备确认，房主当前操作会显示“确认加入”；确认通过且游戏核对完成后才显示可用的开始操作。

## 退出期间 SSH 断开

附近联机会暂时离开普通 Wi-Fi，原 IP 上的 SSH 不可用。正常退出并等待恢复后查看当前 IP。启动失败有独立的 300 秒恢复期限；游戏启动得到原生连接确认后取消启动计时器。诊断日志持久保存在 `/opt/arkos-nearby/logs/`。

## 图形界面打不开

先退出游戏和房间，再重新打开 Options 入口。检查 `/opt/arkos-nearby/logs/` 中的启动记录。报告时附上版本、`doctor` 结果、打开方式、游戏名称和所用核心。

## 报告问题

在 [GitHub Issues](https://github.com/W-Mai/arkos-nearby/issues) 中提供可重复步骤与两端状态。日志发送前删除配对代码、无线密码、私钥和个人游戏路径。画面流畅度问题应附同设备、同核心、同场景的单机与联机对照。
