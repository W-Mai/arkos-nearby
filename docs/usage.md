# 使用说明

## 打开 Howff

| 入口 | 打开内容 |
| --- | --- |
| **Options → Howff Launcher** | 收藏首页与游戏库 |
| **Options → Howff Nearby** | 附近房间与组网入口 |
| 系统主页 **FN + X** | 附近房间与组网入口 |
| 系统游戏列表启动时按住 **X** | 当前游戏的创建／加入房间面板 |
| 收藏或游戏库中长按 **X** | 选中游戏的联机面板 |
| 启动器中 **SELECT** | 附近联机面板 |

## 收藏与游戏库

收藏卡带按屏幕空间排成多行。方向键跨行、跨页移动，页码条随翻页变化；按 **B** 回到第一页。收藏末尾的游戏库卡片按 **A** 或下键展开游戏库，收藏架缩小并保留在上方。**B** 逐级返回，恢复原选中位置。

平台列表显示主机图案和游戏数量，进入平台后查看游戏名称与截图。选中游戏后，短按 **X** 并松开启动单机，长按 **X** 打开联机面板；**A** 打开游戏操作。单机沿用系统的模拟器配置与存档，退出后回到原来的游戏位置。

| 页面 | 按键 | 操作 |
| --- | --- | --- |
| 平台列表 | **Y** | 搜索游戏 |
| 游戏列表、搜索结果 | **Y** | 收藏游戏 |
| 收藏架 | **Y** | 切换名称／最近游玩排序 |
| 收藏游戏的操作面板 | **A** 选择「移出收藏」 | 取消收藏 |
| 游戏列表 | **L / R** | 翻页 |

搜索支持游戏名、文件名、中文名拼音与首字母。方向键选键，**A** 输入，**Y** 退格，**START** 在键盘与结果之间切换，**B** 收起键盘或返回。

## 双机联机

1. 一台选择游戏，打开联机面板并创建房间。
2. 另一台打开附近房间，选中对应房间后按 **A** 加入；房间列表按 **X** 刷新。
3. 首次连接时，房主按 **A** 确认加入请求。
4. 程序自动核对加入者的本地游戏和核心，匹配后继续连接；页面列出本机对应版本时，选中游戏并按 **A**，等待准备完成。
5. 双方准备完成后，房主选择 **开始游戏**。进入游戏后选择双人或连接线模式。

直接打开附近联机时，已连接普通 Wi-Fi 的掌机会先显示房间列表。向下移动或按 **R** 展开「仅组网／选择游戏」，向上移动或按 **L** 展开房间列表。

准备期间，加入者按 **B** 取消或离开，房主按 **B** 关闭房间；完成网络恢复后可以重新选择。游戏结束后，Howff 恢复之前连接的 Wi-Fi。平台与核心的实际支持范围见 [设备与游戏兼容性](compatibility.md)。

## 仅组网

选择 **仅组网**，一台创建房间，另一台选择这个房间加入。连接完成后显示设备地址，按 **A「保持连接，返回系统」**，再从 Ports 打开支持局域网联机的游戏，在游戏里创建或查找房间。

再次打开 Howff Nearby 可以查看当前连接，按 **B「断开并恢复 Wi-Fi」** 结束组网。

## 游戏设置与存档

选中游戏按 **A**，在游戏操作面板中进入：

- **游戏详情**：查看运行核心、BIOS、配置与存档位置，按 **A** 展开条目，按 **B** 收起或返回。
- **游戏设置**：编辑游戏、核心或前端设置，按 **Y** 切换范围，左右修改，**A** 查看来源和写入位置，**X** 保存。
- **存档管理**：查看即时存档、游戏进度和联机存档，选择槽位载入、创建备份或恢复。确认页面显示本次操作的目标文件。

单机沿用原存档，联机会话使用独立存档。文件位置与备份说明见 [数据与存档](data.md)。

## 设置与系统工具

按 **START** 打开设置面板：

| 入口 | 操作 |
| --- | --- |
| 主题与音效 | 切换配色，开启或关闭菜单音效 |
| 系统控制 | 上下选择音量或亮度滑块，左右调节 |
| 系统控制 → 系统工具 → Wi-Fi 设置 | 扫描网络、输入密码、连接与管理已保存的网络 |
| 系统控制 → 系统工具 → 存储空间 | 查看分区容量，按 **A** 展开设备和挂载信息 |
| 设备与好友 | 修改本机名称，查看和移除已配对好友 |
| 应用管理 | 查看版本、诊断、启动方式和安装更新包 |
| 电源 | 确认关机或重启 |

设备重命名支持中文拼音、英文与符号输入。移除好友后，下次加入时重新确认。

在 **应用管理 → 启动方式 → 开机首页** 将收藏设为默认首页，或选择原系统恢复系统游戏列表。独立启动器中的 **返回原系统** 会回到系统游戏列表。
