# 数据与存档

## 个人数据

Howff 将个人数据保存在掌机的 `/opt/howff/` 下：

| 内容 | 文件或目录 |
| --- | --- |
| 收藏、最近游玩与收藏排序 | `library.json` |
| 上次选中的收藏游戏 | `launcher.json` |
| 设备名称 | `device.json` |
| 设备身份与密钥 | `identity.json`、`identity.pk8` |
| 配对与已配对好友 | `pair.json`、`friends.json` |
| 主题与菜单音效 | `ui-theme`、`ui-sound.json` |
| 默认首页 | `launcher-home.json` |
| 存档备份 | `saves/backups/` |

更新、重复安装和卸载保留这些数据。重新安装后继续读取同一台掌机的个人记录。

## 单机存档

单机使用系统原来的游戏进度与即时存档，实际路径由前端、核心和游戏配置决定。在 **Options → Howff Launcher** 的收藏或游戏库中选中游戏，按 **A → 游戏详情** 查看当前路径；在 **游戏设置** 修改存档策略时，保存前会显示生效位置。

在同一游戏的操作面板中选择 **存档管理**，可以载入即时存档槽位、恢复游戏进度和创建备份。选中记录后查看目标文件，再确认操作；载入即时存档前会先备份当前进度，恢复游戏进度后从标题启动。

## 联机存档

联机会话使用 `/run/howff/` 下的独立临时目录，从空存档开始。双方本机的单机存档保持原状，会话结束后清理临时存档。存档管理中的联机分区显示当前房间的私有路径与状态。

## 备份到电脑

先结束游戏和房间，等待 Wi-Fi 恢复，再退出 Howff。在掌机 Options 中开启远程服务，查看当前 IP。在电脑的备份目录中运行以下命令，将 `HANDHELD_IP` 替换为掌机地址：

```sh
ssh ark@HANDHELD_IP 'sudo -n tar -C /opt -czf - howff' > howff-device-backup.tar.gz
```

归档包含该掌机的 Howff 程序与个人文件。原游戏进度和即时存档按「游戏详情」显示的实际路径另行复制。恢复个人记录时，从归档取出上表中的文件与存档备份，放回同一台掌机的原位置；设备身份和配对文件随这份掌机备份私有保存。

## 缓存与日志

`catalog-index.json` 和 `launcher-index.json` 是游戏索引，文件缺失或损坏时会重新生成。`logs/` 保存诊断记录。报告问题时可附上日志，发送前移除配对代码、无线密码、密钥与个人游戏路径。
